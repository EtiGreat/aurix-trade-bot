# AURIX TRADE V3 — Demo Request Workflow

Adds demo-only deposit and withdrawal requests with admin approval/rejection.

IMPORTANT: This build does NOT accept, custody, transfer, or withdraw real funds and does not connect to a live broker/exchange. Do not publish payment addresses for this build. A real-money launch requires compliant payment/custody infrastructure, reconciliation, security controls, applicable KYC/AML procedures, and legal/regulatory review.

Commands: /start, /admin
